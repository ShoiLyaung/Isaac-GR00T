# Research branch scope

This branch is an immutable source archive of the completed GR00T N1.7
Mamba action-generator program.

- Base: `feat/groot-n17-main-h40-r2` at
  `5615f267c990c661a8f116c16165b2b23867d6a1`.
- Source snapshot before this note:
  `638325890bd9e7ac5c9ad5015f952cefeda085f3`.
- Scope: Mamba action mixers, matched training/evaluation runners, CUDA Graph
  execution, serving support, and focused tests.
- Scientific status: qualified negative. The selected student reduced policy
  latency and allocated memory but did not preserve native DiT offline or
  closed-loop capability.
- Intended use: reproducibility and historical reference, not the starting point
  for the active causal-memory method.

No model weights, checkpoints, datasets, run artifacts, or local Agent/Codex
configuration are included by this branch.
